# English and Korean UI

ControlPanel follows ComfyUI's language setting. Select English or Korean in ComfyUI's Settings under the user-interface language option. ControlPanel uses English when the selected language is missing or unsupported.

The React panel and Nodes Manager update when ComfyUI changes `Comfy.Locale`. Command labels use ComfyUI's command translation files and read the current locale. Action-bar labels and tooltips are registered as static strings, so reload the browser page after changing the language to refresh those labels.

ComfyUI loads custom-node translations from the extension's root `locales/<language>/` folders. `main.json` contains setting categories and the namespaced `ComfyUI-ControlPanel` messages used by the custom UI. `settings.json` and `commands.json` use ComfyUI's standard keys for registered settings and commands. Keep English and Korean keys and `{placeholders}` aligned; the frontend i18n tests check both, plus the Korean punctuation rule.

When adding a UI message, add its `ComfyUI-ControlPanel` key to both `locales/en/main.json` and `locales/ko/main.json`, then use `useI18n()` in React or `createTranslator()` in a controller/service. Keep remote catalog text, paths, IDs, command payload values, and external error details unchanged. Add setting and command translations to their respective files using the IDs in `frontend/src/constants.ts` and `frontend/src/index.ts`.

ComfyUI caches custom-node translation discovery for the process lifetime. After adding a new locale directory or translation file, restart ComfyUI and reload the browser page so the host can discover it. No backend node definitions are registered by this extension, so it does not ship `nodeDefs.json`.
